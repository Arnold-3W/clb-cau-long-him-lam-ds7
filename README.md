# CLB Cầu Lông Him Lam – Đường Số 7

Landing page giới thiệu Câu lạc bộ Cầu Lông Him Lam – Đường Số 7, Phường Tân Hưng, TP.HCM.

Sinh hoạt mỗi sáng **5:30 – 7:00**, hằng ngày. Khởi đầu ngày mới với năng lượng, sức khỏe và bạn bè.

## Nội dung trang
- Hero giới thiệu + chỉ số nổi bật
- 7 lợi ích của việc dậy sớm chơi cầu lông
- Video thực tế tại sân
- Lịch tập & địa điểm
- Thư viện ảnh
- Cảm nhận thành viên
- Thông tin liên hệ / tham gia

## Cấu trúc
```
index.html      # Trang chính
styles.css      # Giao diện
assets/         # Hình ảnh & video
```
